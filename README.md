# AMC Construções — Website Institucional & CMS

Website institucional moderno desenvolvido para a AMC Construções utilizando Next.js 16, React 19 e MongoDB, com foco em performance, SEO e experiência do utilizador.

## ✨ Sobre o projeto

Este projeto foi desenvolvido para modernizar completamente a presença digital da AMC Construções, substituindo o website anterior por uma plataforma mais rápida, escalável e otimizada para motores de busca.

Além da reformulação visual e estrutural do website institucional, também foi implementado um CMS interno para gestão de conteúdos do blog, permitindo que a equipa administrativa publique, edite e organize artigos de forma simples e intuitiva.

A aplicação foi construída com foco em:

- Alta performance
- SEO avançado
- Responsividade em todos os dispositivos
- Boa experiência do utilizador
- Facilidade de manutenção e escalabilidade

---

## 🚀 Tecnologias utilizadas

### Frontend

- Next.js 16
- React 19
- TypeScript
- TailwindCSS v4
- ShadCN UI
- Lucide React

### Backend

- MongoDB
- Mongoose
- JWT Authentication

### Serviços e integrações

- Cloudinary
- Google Maps API
- TipTap Editor
